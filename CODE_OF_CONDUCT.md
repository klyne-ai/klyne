# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc21] as its
code of conduct.

The full text is available at the link below. By participating in this
project (issues, pull requests, discussions, or any other channel) you
agree to abide by its terms.

[cc21]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Concerns about behaviour in project spaces can be raised privately via
GitHub's private vulnerability reporting channel (see
[SECURITY.md](SECURITY.md)) or by opening a private discussion with a
maintainer. We will respond within 72 hours.
